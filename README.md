# تحدي ٣٠ يوم

تطبيق أندرويد لمتابعة تحدٍّ يومي لمدة ٣٠ يومًا (يبدأ الأحد ٨ نوفمبر ٢٠٢٦):

- **الصلوات الخمس في وقتها** مع مواقيت محسوبة لمدينتك وتنبيه عند كل أذان، وعدّاد للصلاة القادمة واتجاه القبلة.
- **وِرد القرآن** بعدد صفحات تختاره، مع حفظ آخر صفحة وصلت إليها في المصحف.
- **المشي ٥ كم** يُحسب تلقائيًا من عدّاد خطوات الجوال، أو تمرين بديل بالدقائق.
- **بدون سكر، بدون خبز، وحفظ النفس** — مع صفحة «أحتاج مساعدة الآن» لخطوات عملية عند الرغبة.
- **عادات إضافية مقترحة**: أذكار الصباح والمساء، الوتر، الماء، النوم المبكر، الرواتب، الضحى، صيام الاثنين والخميس، الصدقة…
- شبكة الثلاثين يومًا، الإحصاءات، السلاسل المتتالية، والمحطات (٧ / ١٤ / ٢١ / ٣٠).
- خط **ثمانية** (Thmanyah Sans)، وضع فاتح وداكن، وكل البيانات محفوظة على الجهاز فقط.

## الحصول على ملف APK

كل دفع إلى فرع `main` يبني التطبيق تلقائيًا عبر GitHub Actions وينشر ملف `Tahadi30.apk` في صفحة **Releases**.
من الجوال: افتح صفحة Releases ← آخر إصدار ← حمّل `Tahadi30.apk` ← ثبّته (اسمح بالتثبيت من مصادر غير معروفة).
